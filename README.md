## How to Deploy to NEW REPO (2 minutes):

### If you create NEW repo (recommended for fresh start):

1. **Create new repo on GitHub:**
   - Go to github.com/new
   - Name: `trl-website` or `The-Right-Lifestyle-New`
   - Public, no README

2. **On your PC:**
   ```bash
   mkdir trl-website
   cd trl-website
   # Copy index.html, style.css, script.js from this folder into here
   # Also copy logo.svg, og-image.png, privacy.html, robots.txt, sitemap.xml if you want
   git init
   git add .
   git commit -m "TRL V3 Professional - PK vs Global, WhatsApp direct"
   git branch -M main
   git remote add origin https://github.com/YOURUSERNAME/trl-website.git
   git push -u origin main
   ```

3. **Enable GitHub Pages:**
   - Repo → Settings → Pages → Source: main branch, root → Save
   - Wait 1-2 mins → Your site live at https://YOURUSERNAME.github.io/trl-website/

### If you want to REPLACE existing repo `The-Right-Lifetsyle`:

1. Clone existing:
   ```bash
   git clone https://github.com/therightlifestyle/The-Right-Lifetsyle.git
   cd The-Right-Lifetsyle
   ```

2. Replace files:
   - Overwrite index.html with new index.html from this folder
   - Overwrite style.css with new style.css
   - Overwrite script.js with new script.js
   - Keep other files (logo.svg, privacy.html, etc.)

3. Push:
   ```bash
   git add index.html style.css script.js
   git commit -m "V3 Professional - No fixed pricing, PK/Global choice, WhatsApp direct"
   git push origin main
   # GitHub Pages auto updates in 1-2 mins
   ```
